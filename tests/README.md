# tests/

Bileşenler arası **uçtan uca ve şartname kabul testleri** burada tutulur (ör. "ET-2026-001'den etkilenen marketler A/B/C = 30/25/30 paket").

Birim testleri, dilin alışılmış düzenine uygun olarak her bileşenin kendi klasöründe durur (`backend/`, `web/`, `android/`, `ml/`).

Test listesi ve hangi testin hangi gereksinimi doğruladığı: `docs/testing_strategy.md`.

**Durum:** Henüz test kodu yok.
